# Fieldwork sales workspace

Local-first sales and marketing application. The [service](sales-service/README.md) contains the React interface, PHP API, MySQL schema, and checks. The [Codex plugin source](sales-workspace/) connects chat to the local service and guides first-run setup.

This is an early local implementation. Lead intake, assignment, follow-up tasks, and owner-managed team accounts work locally. Email, SMS, WhatsApp, scheduled sending, desktop alarms, and hosted deployment are still planned. See [implementation progress](sales-service/PROGRESS.md) for current status and limitations.
